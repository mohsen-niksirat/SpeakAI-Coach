# SpeakAI Coach

[English](README.md) | **فارسی**

مربی مکالمه صوتی با هوش مصنوعی، برای آیلتس و تمرین روزمرهٔ انگلیسی. با یک مربی هوشمند روی اتصال کم‌تأخیر WebSocket صحبت کن، در حین مکالمه تصحیح گرامری و ثبت واژگان بگیر و در پایان هر جلسه گزارش نمرهٔ تخمینی آیلتس با ارزیابی هوش مصنوعی دریافت کن.

با **Google Gemini Live**، **OpenAI Realtime** و هر دروازهٔ سازگاری کار می‌کند — کلیدهای API مال خودت است و هرگز از مرورگرت خارج نمی‌شوند.

![تنظیمات SpeakAI Coach](screenshot%2001.jpg)

*تنظیمات: نقش مربی را انتخاب کن، ارائه‌دهندهٔ صدا و گزارش را جداگانه تعیین کن و چند کلید API برای هر ارائه‌دهنده مدیریت کن.*

## امکانات

- **گفت‌وگوی صوتی بلادرنگ با تأخیر فوق‌پایین** — Gemini Live یا OpenAI Realtime روی یک WebSocket دوطرفه؛ بدون خط لولهٔ STT → LLM → TTS.
- **قطع طبیعی حرف مدل (barge-in)** — هر لحظه وسط حرف مربی بپر، پخش بلافاصله قطع می‌شود.
- **پروایدر سفارشی چندگانه** — هر تعداد ارائه‌دهنده با نام، نوع، آدرس پایه، مدل و کلیدها؛ ارائه‌دهندهٔ صدا و گزارش مستقل انتخاب می‌شوند (مثلاً صدا با Gemini و گزارش با OpenRouter).
- **چرخش کلید** — چند کلید برای یک ارائه‌دهنده بگذار؛ در صورت خطا یا سقف نرخ، خودکار کلید بعدی امتحان می‌شود و قطع وسط جلسه هم با اتصال مجدد محدود همراه است.
- **صدای مرورگری برای پروایدرهای چتی** — هر ارائه‌دهندهٔ فقط-متنی (OpenRouter، VyceAI، DeepSeek و…) هم با گفتار تشخیص گفتار و تبدیل متن به صدای مرورگر به‌عنوان مربی صوتی کار می‌کند.
- **نقش‌های مربی** — مصحح آیلتس، همصحبت صمیمی، مصاحبه‌گر کاری، هم‌بحث.
- **ابزارهای مربی زنده** — واژگان و خطاهای گرامری هم‌زمان با مکالمه از طریق function calling ثبت می‌شوند.
- **متن زندهٔ گفتگو** — کل مکالمه به‌صورت زنده نوشته می‌شود.
- **گزارش جلسه** — در پایان جلسه، متن گفتگو با چهار معیار رسمی آیلتس (روانی و انسجام، منابع واژگانی، دامنه و دقت دستوری، تلفظ) ارزیابی و نمرهٔ کل به‌همراه نقاط قوت و بهبود ارائه می‌شود.
- **خروجی سازگار با لایتنر** — دک واژگان به CSV، JSON یا متن Anki خروجی می‌گیرد و بین جلسات در مرورگر می‌ماند.
- **رابط چندزبانه انگلیسی/فارسی** — از هدر عوض کن؛ چیدمان فارسی کاملاً راست‌به‌چپ است.
- **کلاینت‌محور و BYOK** — بدون سرور، بدون حساب کاربری؛ همهٔ کلیدها در localStorage مرورگر.

## امتحان کن

با هر push به `main` نسخهٔ build شده روی GitHub Pages منتشر می‌شود:

`https://mohsen-niksirat.github.io/SpeakAI-Coach/`

(یک بار در تنظیمات ریپو فعال کن: **Settings → Pages → Source: GitHub Actions**.)

## توسعه محلی

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # خروجی نهایی در dist/
```

در **Settings** یک ارائه‌دهنده اضافه کن، کلید(ها) را بزن، نقش و صدا را انتخاب کن و جلسه را شروع کن. مجوز میکروفون لازم است.

## انواع ارائه‌دهنده

| نوع | مکالمهٔ صوتی | گزارش جلسه | نمونهٔ آدرس پایه |
|---|---|---|---|
| Gemini Live | بلادرنگ | Gemini `generateContent` | `https://generativelanguage.googleapis.com` |
| OpenAI Realtime | بلادرنگ | OpenAI `chat/completions` | `https://api.openai.com/v1` |
| سازگار با OpenAI | صدای مرورگر (STT → چت → TTS) | `chat/completions` | `https://openrouter.ai/api/v1` |

نکته‌ها:

- **صدای مرورگر** با هر ارائه‌دهندهٔ متنی کار می‌کند: گفتارت با Web Speech API تایپ می‌شود، پاسخ از چت‌مدل می‌آید و مرورگر آن را می‌خواند. کروم یا اِج لازم دارد و کمی کندتر از صدای بلادرنگ است.
- کلیدها طبق پروتکل فرستاده می‌شوند: Gemini با `?key=`، Realtime با زیرپروتکل مرورگر OpenAI و `?api_key=` برای دروازه‌ها، و چت با `Authorization: Bearer`.
- `Report Model` می‌تواند یک مدل متنی ارزان‌تر برای ارزیابی پایان جلسه باشد.
- چرخش کلید همیشه از کلید فعال شروع می‌شود و فقط موقع خطا جلو می‌رود؛ پس کلید سالم هرگز رد نمی‌شود.
